# WACDO - gestionnaire des affectations

**WacDo** est une application de gestion des affectations des collaborateurs dans les différents restaurants de Wacdo.

---

## 🚀 Fonctionnalités

- 👤 Gestion des collaborateurs
- 🍽️ Gestion des restaurants
- 🧾 Suivi des affectations actuelles et historiques
- 🏷️ Gestion des fonctions
- 🔍 Filtrage
- 🔐 Authentification
- 🧪 Tests unitaires et d’intégration avec JUnit & MockMvc

---

## ⚙️ Prérequis

- Java 21
- Maven
- MySQL 8.0.35

---
## 🧩 Installation et lancement

1. **Cloner le dépôt :**
```bash
git clone https://https://github.com/Yann-vdv/wacdo
cd wacdo
```
2. **Lancer l’application :**
```bash
mvn spring-boot:run
```
3. Accéder au site :
http://localhost:8080
https://wacdo-9gkn.onrender.com/
